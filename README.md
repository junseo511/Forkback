# 🍴 Forkback

**“서울의 진짜 맛집을 알고 싶다면, 너가 사는 뉴욕의 맛집을 공유해줘.”**

Forkback은 전 세계 로컬 맛집 리스트를 서로 **교환**하며 열람하는 미식 정보 큐레이션 플랫폼입니다.  
리뷰/광고 기반 추천이 아닌, **사용자 간 직접 추천 콘텐츠**를 통해  
진짜 로컬의 맛집 정보를 광고 없이 경험할 수 있습니다.

---

## 🌍 배포 주소

👉 [https://v0-forkback-clone.vercel.app](https://v0-forkback-clone.vercel.app)

---

## 🔑 핵심 기능

- 나라 및 도시별 리스트 해금 기능
- 맛집 리스트 업로드 (사진, 위치, 설명 등)
- 다른 사용자가 게시한 가게 상태 피드백 기능 (폐업, 이사, 별로였음 등)
- 다른 도시 리스트 열람을 위한 콘텐츠 교환 구조
- 리스트 열람/저장 시 포인트 적립 및 알림
- 피드백 기능을 통한 콘텐츠 순환 구조
- 외국인 대상 자연스러운 가게 노출 기능

## 📌 사용자 시나리오 & 사용자 스토리

### ✈️ Alex – 여행자의 맛집 찾기 여정

**상황**: 서울 여행을 앞두고, 광고 없는 로컬 맛집 정보를 원함

**사용자 시나리오**:
- Forkback 앱 실행
- 도시 선택: ‘서울’ → 리스트 잠김 확인
- “당신 도시의 리스트를 작성해야 열람 가능” 메시지
- 뉴욕의 숨은 맛집 3곳 리스트 등록
- 서울 리스트 열람 → 저장 → 여행 시 방문

**사용자 스토리**:
> "여행자로서, 저는 외국 도시의 진짜 로컬 맛집을 알고 싶습니다. 그래서 더 깊이 있는 여행 경험을 하고 싶습니다."

**인수 조건**:
- **Given**: 사용자가 서울 리스트를 열람하려 할 때
- **When**: 본인의 지역 리스트를 업로드하면
- **Then**: 서울 리스트 열람 권한이 해제된다

**사용자 스토리**:
> "로컬 사용자로서, 저는 제가 좋아하는 맛집 리스트가 다른 사람에게 실제로 쓰이고 보상받고 싶습니다."

**인수 조건**:
- **Given**: 외국인이 내 리스트를 열람했을 때
- **When**: 열람이 완료되면
- **Then**: 포인트가 자동 적립되고 알림이 발송된다

**사용자 스토리**:
> "소상공인으로서, 저는 제 가게가 외국인의 로컬 추천 리스트에 자연스럽게 포함되길 바랍니다."

**인수 조건**:
- **Given**: 내 가게가 포함된 리스트가 외국인에게 열람될 때
- **When**: 리스트가 저장되거나 후기 피드백이 남겨지면
- **Then**: 내 대시보드에서 피드백 및 열람 통계를 확인할 수 있다

### 🧳 Layla – 여행자의 실패한 방문과 피드백 루틴

**상황**: Forkback에서 본 서울 리스트를 따라 찾아갔지만, 해당 가게가 폐업 상태였음

**사용자 시나리오**:
- Forkback에서 ‘홍대 로컬 추천 리스트’ 열람
- 리스트 중 하나인 맛집을 지도 기반으로 찾아감
- 폐업되어 문이 닫혀 있음
- 앱 내 “가게 상태 알리기” 버튼 클릭 → “폐업했어요” 선택
- 리스트 작성자에게 알림 → 포인트 지급
- 다음 여행자를 위해 최신 정보 공유 → 만족감

**사용자 스토리**:
> “여행자로서, 저는 다른 사람이 이미 다녀온 정보를 바탕으로 닫힌 가게를 피하고 싶습니다. 그래서 여행 중 낭비되는 시간을 줄이고 싶습니다.”

**인수 조건**:
- **Given**: 사용자가 리스트에서 특정 가게를 방문했을 때
- **When**: 폐업 상태거나 이상이 있을 경우 “가게 상태 알리기” 기능을 사용하면
- **Then**: 해당 정보가 리스트 작성자와 시스템에 반영되고, 다음 사용자에게 표시된다
